# Marshal Mobile PR7 · 全功能 UI/UE 交互设计规范与定稿说明

## 0. 文档元信息
- **分支归属**：`feat/mobile-pr7-apple`
- **对应原型文件**：[`design/mobile-pr7-prototype.html`](./mobile-pr7-prototype.html)（单文件自包含可点击高保真原型 + 交互线框图双模预览）
- **基线对齐**：桌面端 `plugin-build`（`0.2.0-agent-groups.32` / `rjr/cx/pr6-routing-memory-fixes`）与移动端 `mobile`（`v0.7.6` Capacitor 双端工程）
- **设计语言**：Apple Human Interface Guidelines（双层材质：实底不透明内容卡片 + 顶/底导航与模态抽屉磨砂半透明），跨 iOS 与 Android 双端统一体验

## 1. 核心角色与连接边界
- **纯出站移动控制器（Mobile Node）**：手机端持有 `Bearer mph1.*` 凭证，不存储任何大模型 API Key、不监听入站端口；通过官方或自建 `marshal-hub` 连接边缘桌面主机（`Bearer mnd1.*`），直接共享桌面端已登录的 DSH / Codex / Claude 账号与算力额度。
- **「手机连接」一码配齐**：扫描桌面端生成的 60 秒一次性动态二维码（`marshal://pair?code=…&hub=…`），一步配齐 Hub 通道、跨机群聊会话票据与工作区上下文。

## 3. 关键交互与体验定稿细则

### 3.1 工单：详情确认与工单群解耦
1. **点工单先弹「工单详情」**：列表卡片保持克制，点击后弹出结构化「工单详情」抽屉，清晰展示四步执行阶段条、待确认事项摘要与补丁变更文件 Diff（遵循 `48 KiB` 文本补丁上限）。
2. **详情内拇指区直接拍板**：在工单详情底部直接执行「确认批准执行 / 追加批次重试 / 驳回关单」，携带 `baseRevision` 乐观锁防止多端并发覆盖。
3. **一键进出专属工单群**：详情内提供醒目的「进入工单群查看各 Agent 讨论 ›」入口，跳转至 `会话 → 工单群` 查看 Leader / Coder / Reviewer 完整协作记录；左上角保留 `< 工单详情` 原路返回，右上角保留快捷「确认操作」入口。

### 3.2 会话：对齐 Claude / ChatGPT / Gemini 手机端体验
1. **无按钮上滑自动加载历史**：取消生硬的「读取更早历史」按钮；用户在消息流顶部向上滑动 / 下拉或滚轮上滚时，自动展示顶部原生加载指示器，分页拉取 `history.result` 只读历史（不触发 `resume` 推理）并锁定当前阅读滚动锚点。
2. **去边框 AI 排版与可折叠思考链**：用户消息采用柔和浅底圆角气泡（`--ios-user-bubble`），AI 回复采用全宽无边框排版，内联展示可折叠「已深度思考 N 秒 ›」推理摘要与轻量胶囊式工具调用记录。
3. **去对勾悬浮胶囊输入舱**：
   - 左侧圆形 `+` 键：呼出拍照识别、相册图片、本地文件分片上传（256 KiB 分片 + SHA-256 校验）。
   - 中部纯净模型胶囊（如 `DeepSeek R1 ▾`）与开关高亮式思考胶囊（如 `思考 · 高`）：**全程不使用任何对勾（✓/☑）**。
   - **思考强度单列抽屉**：点按思考胶囊仅弹出清爽的**垂直单列列表**（`关闭 / 低 / 中 / 高`，右侧标注 `当前`），不叠放重复的横向分段条。
   - 右侧圆形动作键：空闲时为发送箭头 `↑`，流式生成中自动变为停止方块 `■`。
4. **新建会话直选主机与智能体**：点击右上角新建图标弹出抽屉，支持切换「新建单聊会话 | 多智能体群聊」；单聊下按 **「1. 选择运行主机 → 2. 选择该主机可用智能体（或纯净直连）→ 3. 工作目录」** 创建，进入带快捷提问建议的欢迎页。

### 3.3 智能体与真实 3D 记忆星系
1. **桌面同源 3D `MemoryGalaxy` 实时绘制**：直接复用桌面端 `plugin-build/client/index.js` 与 `sqlite-store.js` 的图谱算法——以 FNV-1a 哈希生成三维初始坐标，经 110 步三维库仑斥力、中心引力与 `tag`/`session` 弹簧边收敛后，通过 HTML5 `<canvas>` 透视投影实时渲染深空背景与发光星体。
2. **多维视觉编码**：
   - 颜色区分记忆类型：画像 `#f6c35c`、决策 `#5aa7ff`、事实 `#4fd1c5`、片段 `#b18cff`、交接 `#ff9f5a`、场景 `#7bd88f`。
   - 半径映射重要度与访问频次；透明度映射清晰度衰减（`vivid` → `clear` → `fuzzy` → `trace`）；外层金圈标识 `pinned` 固定记忆，琥珀脉冲圈标识待审批全局提案。
3. **手势与详情联动**：支持单指拖拽 360° 轨道旋转、双指捏合/滚轮缩放、点选任意三维星体实时刷新下方详情卡片（查看触发场景 Cue、标签、执行全局提案 `同意(全部会话) / 仅单聊可见 / 拒绝`，或内联二次点按确认删除并写入防复活墓碑）。
