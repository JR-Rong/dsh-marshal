# dsh-marshal v0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让一台机器上的浏览器列出、观察并接管另一台机器上的 DSH 会话，包含思考流、工具卡片和双向的阻断式提问。

**Architecture:** 单个 npm 包，按 `config.role` 装配成 hub 或 node。node 主动外连 hub 的 `/marshal/uplink` WebSocket；hub 维护设备注册表、按 target 路由指令、把事件扇出到 `/marshal/api/stream` 的 SSE 订阅者；页面由 `/marshal` 直接返回静态 HTML。DSH 交互全部收敛在 `adapters/dsh/surface.ts` 一个文件里。

**Tech Stack:** TypeScript 5.9（纯 ESM，Node ≥ 24）、zod 4、ws 8、vitest 4、Cordis 插件（`export function apply(ctx, config)`）

**Docs:** [设计文档](../specs/2026-10-29-marshal-design.md) · [架构设计](../specs/2026-10-29-marshal-architecture.md)

```ts
export type Role = 'hub' | 'node'
export type Privacy = 'metadata' | 'content'
export type Relay = 'off' | 'remote'

export interface MarshalConfig {
  readonly role: Role
  readonly hubUrl?: string
  readonly token?: string
  readonly dashboardToken?: string
  readonly deviceName: string
  readonly privacy: Privacy
  readonly questionRelay: Relay
  readonly answerTimeoutMs: number
  readonly approvalRelay: Relay
  readonly ringBufferMinutes: number
  readonly redaction: readonly string[]
  readonly devicesFile: string
}

function requireString(raw: Record<string, unknown>, key: string, missing: string[]): string | undefined {
  const value = raw[key]
  if (typeof value !== 'string' || value.trim() === '') { missing.push(key); return undefined }
  return value.trim()
}

function parseRelay(raw: unknown, key: string): Relay {
  const value = raw ?? 'off'
  if (value !== 'off' && value !== 'remote') throw new Error(`marshal: config.${key} must be "off" or "remote"`)
  return value
}

export function parseConfig(raw: unknown, hostname: string): MarshalConfig {
  if (raw === null || typeof raw !== 'object') throw new Error('marshal: config must be an object')
  const input = raw as Record<string, unknown>
  const role = input.role
  if (role !== 'hub' && role !== 'node') throw new Error('marshal: config.role must be "hub" or "node"')

  const missing: string[] = []
  let hubUrl: string | undefined
  let token: string | undefined
  let dashboardToken: string | undefined
  if (role === 'node') {
    hubUrl = requireString(input, 'hubUrl', missing)
    token = requireString(input, 'token', missing)
    if (missing.length > 0) throw new Error(`marshal: node config is missing ${missing.join(', ')}`)
    if (!hubUrl!.startsWith('wss://')) throw new Error('marshal: config.hubUrl must be a wss:// URL')
    if (token!.length < 16) throw new Error('marshal: config.token must be at least 16 characters')
  } else {
    dashboardToken = requireString(input, 'dashboardToken', missing)
    if (missing.length > 0) throw new Error(`marshal: hub config is missing ${missing.join(', ')}`)
    if (dashboardToken!.length < 16) throw new Error('marshal: config.dashboardToken must be at least 16 characters')
  }

  const privacy = input.privacy ?? 'metadata'
  if (privacy !== 'metadata' && privacy !== 'content') throw new Error('marshal: config.privacy must be "metadata" or "content"')

  const answerTimeoutMs = input.answerTimeoutMs ?? 300_000
  if (typeof answerTimeoutMs !== 'number' || !Number.isFinite(answerTimeoutMs) || answerTimeoutMs <= 0) {
    throw new Error('marshal: config.answerTimeoutMs must be a positive number')
  }

  const deviceName = typeof input.deviceName === 'string' && input.deviceName.trim() !== ''
    ? input.deviceName.trim()
    : hostname

  return {
    role,
    ...(hubUrl === undefined ? {} : { hubUrl }),
    ...(token === undefined ? {} : { token }),
    ...(dashboardToken === undefined ? {} : { dashboardToken }),
    deviceName,
    privacy,
    questionRelay: parseRelay(input.questionRelay, 'questionRelay'),
    answerTimeoutMs,
    approvalRelay: parseRelay(input.approvalRelay, 'approvalRelay'),
    ringBufferMinutes: typeof input.ringBufferMinutes === 'number' ? input.ringBufferMinutes : 15,
    redaction: Array.isArray(input.redaction) ? input.redaction.filter((x): x is string => typeof x === 'string') : [],
    devicesFile: typeof input.devicesFile === 'string' ? input.devicesFile : `${process.env.HOME ?? '.'}/.dsh-marshal/devices.json`,
  }
}
```

```ts
import { z } from 'zod'

export const MAX_FRAME_BYTES = 1_048_576

export class FrameError extends Error {}

export const MARSHAL_KINDS = [
  'session.updated', 'session.removed', 'turn.started', 'turn.completed',
  'reasoning.delta', 'message.delta', 'message.completed',
  'tool.started', 'tool.output', 'tool.completed',
  'input.requested', 'input.resolved', 'capability.changed', 'error',
] as const

export const MarshalKind = z.enum(MARSHAL_KINDS)
export type MarshalKind = z.infer<typeof MarshalKind>

export const COMMAND_OPS = ['prompt', 'resume', 'create', 'interrupt', 'answer', 'cancel', 'configure'] as const

const Target = z.object({
  device: z.string().min(1),
  agent: z.string().min(1),
  sessionId: z.string().min(1),
})

const Hello = z.object({
  v: z.literal(1), type: z.literal('hello'),
  device: z.string().min(1), token: z.string().min(16),
  agents: z.array(z.string()),
})

const Event = z.object({
  v: z.literal(1), type: z.literal('event'),
  device: z.string().min(1), agent: z.string().min(1), sessionId: z.string().min(1),
  seq: z.number().int().nonnegative(), ts: z.string(),
  kind: MarshalKind, payload: z.unknown(),
})

const Command = z.object({
  v: z.literal(1), type: z.literal('command'),
  id: z.string().min(1), idempotencyKey: z.string().min(1), deadline: z.number(),
  op: z.enum(COMMAND_OPS), target: Target, args: z.unknown().optional(),
})

const Ack = z.object({
  v: z.literal(1), type: z.literal('ack'),
  id: z.string().min(1), ok: z.boolean(),
  result: z.unknown().optional(), code: z.string().optional(), message: z.string().optional(),
})

export const FrameSchema = z.discriminatedUnion('type', [Hello, Event, Command, Ack])
export type Frame = z.infer<typeof FrameSchema>
export type EventFrame = z.infer<typeof Event>
export type CommandFrame = z.infer<typeof Command>
export type HelloFrame = z.infer<typeof Hello>
export type AckFrame = z.infer<typeof Ack>

export function encodeFrame(frame: Frame): string {
  return JSON.stringify(frame)
}

export function decodeFrame(text: string): Frame {
  if (Buffer.byteLength(text, 'utf8') > MAX_FRAME_BYTES) throw new FrameError('marshal: frame too large')
  let json: unknown
  try { json = JSON.parse(text) } catch { throw new FrameError('marshal: frame is not JSON') }
  const parsed = FrameSchema.safeParse(json)
  if (!parsed.success) throw new FrameError(`marshal: invalid frame: ${parsed.error.issues[0]?.path.join('.') ?? '?'} ${parsed.error.issues[0]?.message ?? ''}`.trim())
  return parsed.data
}
```

```ts
export type Lookup = { hit: true; result: unknown } | { hit: false }

/** 记住已受理指令的结果，防止重连后重复执行。 */
export class CommandLog {
  private readonly entries = new Map<string, { at: number; result: unknown }>()

  constructor(
    private readonly ttlMs = 30_000,
    private readonly limit = 512,
    private readonly now: () => number = Date.now,
  ) {}

  remember(key: string, result: unknown): void {
    this.prune()
    // 先删再插，重复 key 才会移到 Map 末尾，淘汰顺序才是真正的 LRU。
    this.entries.delete(key)
    this.entries.set(key, { at: this.now(), result })
    while (this.entries.size > this.limit) {
      const oldest = this.entries.keys().next()
      if (oldest.done === true) break
      this.entries.delete(oldest.value)
    }
  }

  lookup(key: string): Lookup {
    this.prune()
    const entry = this.entries.get(key)
    return entry === undefined ? { hit: false } : { hit: true, result: entry.result }
  }

  private prune(): void {
    const cutoff = this.now() - this.ttlMs
    for (const [key, entry] of this.entries) {
      if (entry.at < cutoff) this.entries.delete(key)
    }
  }
}
```

```ts
export interface Sender { send(text: string): void }

export interface DeviceSeed {
  readonly id: string
  readonly name: string
  readonly agents: readonly string[]
}

export interface DeviceView extends DeviceSeed {
  readonly connectedAt: number
  readonly lastSeen: number
}

interface Slot { readonly record: DeviceView; readonly sender: Sender }

export class DeviceRegistry {
  private readonly devices = new Map<string, Slot>()

  attach(seed: DeviceSeed, sender: Sender, now: number): void {
    this.devices.set(seed.id, {
      record: { ...seed, connectedAt: now, lastSeen: now },
      sender,
    })
  }

  detach(id: string): void { this.devices.delete(id) }

  touch(id: string, now: number): void {
    const slot = this.devices.get(id)
    if (slot !== undefined) slot.record = { ...slot.record, lastSeen: now }
  }

  get(id: string): Slot | undefined { return this.devices.get(id) }

  list(_now: number): DeviceView[] { return [...this.devices.values()].map(slot => slot.record) }

  expire(now: number, ttlMs: number): string[] {
    const expired: string[] = []
    for (const [id, slot] of this.devices) {
      if (now - slot.record.lastSeen > ttlMs) { this.devices.delete(id); expired.push(id) }
    }
    return expired
  }
```

```ts
import type { EventFrame } from '../wire/frames.ts'

const MAX_DEPTH = 6

/** 在离开源机器前替换敏感片段；超深对象原样保留，避免遍历失控。 */
export function redact(value: unknown, patterns: readonly RegExp[], depth = 0): unknown {
  if (typeof value === 'string') {
    return patterns.reduce((text, pattern) => text.replace(pattern, '***'), value)
  }
  if (depth >= MAX_DEPTH || value === null || typeof value !== 'object') return value
  if (Array.isArray(value)) return value.map(item => redact(item, patterns, depth + 1))
  const out: Record<string, unknown> = {}
  for (const [key, item] of Object.entries(value)) out[key] = redact(item, patterns, depth + 1)
  return out
}

/** `privacy: metadata` 时把正文换成尺寸信息；默认档就是这一层。 */
export function stripContent(event: EventFrame): EventFrame {
  const payload = (event.payload ?? {}) as Record<string, unknown>
  const chars = (value: unknown): number => (typeof value === 'string' ? value.length : JSON.stringify(value ?? '').length)

  switch (event.kind) {
    case 'reasoning.delta':
    case 'message.delta':
      return { ...event, payload: { chars: chars(payload.text), redacted: true } }
    case 'tool.started': {
      const keys = typeof payload.arguments === 'object' && payload.arguments !== null && !Array.isArray(payload.arguments)
        ? Object.keys(payload.arguments as Record<string, unknown>)
        : []
      return { ...event, payload: { callId: payload.callId, name: payload.name, argumentKeys: keys } }
    }
    case 'tool.output':
    case 'tool.completed':
      return { ...event, payload: { callId: payload.callId, chars: chars(payload.content), redacted: true } }
    default:
      return event
  }
}
```

`stripContent` 的 `redacted: true` 是给页面用的：它据此渲染"思考中（128 字）"而不是空卡片。

```ts
import type { IncomingMessage, Server } from 'node:http'
import type { Duplex } from 'node:stream'
import { WebSocketServer, type WebSocket } from 'ws'
import type { WebServerLike } from '../dsh-types.ts'
import { decodeFrame, encodeFrame, type Frame } from '../wire/frames.ts'
import { findByToken, type DeviceEntry } from './devices.ts'
import type { DeviceRegistry } from './registry.ts'

export const UPLINK_PATH = '/marshal/uplink'

/** 谁持有 HTTP upgrade 事件。hub 只依赖这个端口，不关心底下是 DSH 还是裸 node。 */
export interface UpgradePort {
  open(handler: (req: IncomingMessage, socket: Duplex, head: Buffer) => void): () => void
}

export const nodeServerPort = (server: Server): UpgradePort => ({
  open(handler) {
    server.on('upgrade', handler)
    return () => { server.off('upgrade', handler) }
  },
})

/** 走 DSH 的 registerUpgrade：DSH 会销毁没匹配到路由的 upgrade 连接，因此这里只登记一条路径。 */
export const webServerPort = (webServer: WebServerLike): UpgradePort => ({
  open(handler) { return webServer.registerUpgrade({ path: UPLINK_PATH, handler }) },
})

export interface HubSocketOptions {
  readonly port: UpgradePort
  readonly registry: DeviceRegistry
  readonly devices: readonly DeviceEntry[]
  readonly now: () => number
  readonly heartbeatMs?: number
  readonly onFrame?: (deviceId: string, frame: Frame) => void
}

export interface HubSocketHandle {
  dispose(): void
  closeDevice(deviceId: string, code: number, reason: string): void
}

export function mountHubSocket(options: HubSocketOptions): HubSocketHandle {
  const { registry, devices, now } = options
  const wss = new WebSocketServer({ noServer: true, maxPayload: 1_048_576 })
  const alive = new WeakMap<WebSocket, boolean>()
  const deviceOf = new WeakMap<WebSocket, string>()

  const onUpgrade = (req: IncomingMessage, socket: Duplex, head: Buffer): void => {
    const header = req.headers.authorization ?? ''
    const token = header.startsWith('Bearer ') ? header.slice(7) : ''
    const device = findByToken(devices, token)
    if (device === undefined) { socket.destroy(); return }

    wss.handleUpgrade(req, socket, head, ws => {
      alive.set(ws, true)
      ws.on('pong', () => alive.set(ws, true))
      ws.on('message', data => {
        let frame: Frame
        try { frame = decodeFrame(String(data)) } catch { ws.close(4400, 'frame-invalid'); return }
        if (deviceOf.get(ws) === undefined) {
          if (frame.type !== 'hello') { ws.close(4401, 'auth-failed'); return }
          if (frame.device !== device.id || frame.token !== token) { ws.close(4401, 'auth-failed'); return }
          deviceOf.set(ws, device.id)
          registry.attach({ id: device.id, name: device.name, agents: frame.agents }, { send: text => ws.send(text) }, now())
          ws.on('close', () => registry.detach(device.id))
          ws.send(encodeFrame({ v: 1, type: 'ack', id: 'hello', ok: true }))
          return
        }
        if (frame.type === 'event') registry.touch(device.id, now())
        options.onFrame?.(device.id, frame)
      })
    })
  }
  const closePort = options.port.open(onUpgrade)

  const timer = setInterval(() => {
    for (const ws of wss.clients) {
      if (alive.get(ws) === false) { ws.terminate(); continue }
      alive.set(ws, false)
      ws.ping()
    }
  }, options.heartbeatMs ?? 30_000)

  return {
    dispose() {
      clearInterval(timer)
      closePort()
      for (const ws of wss.clients) ws.terminate()
      wss.close()
    },
    closeDevice(deviceId, code, reason) {
      for (const ws of wss.clients) if (deviceOf.get(ws) === deviceId) ws.close(code, reason)
    },
  }
}
```

注意三点，别改回去：

- 不写 `wss.on('connection')`：`handleUpgrade` 的回调就是连接入口，先握手再认设备，未发 `hello` 的 socket 不进注册表。
- 不在 `src/index.ts` 里再调一次 `registerUpgrade`：DSH 对重复路径直接抛错。
- 不直接 `server.on('upgrade')`：DSH 的 `webServer` 持有那个事件，走 `webServerPort`。

```ts
import { WebSocket } from 'ws'
import { encodeFrame, type EventFrame } from '../wire/frames.ts'

export interface NodeLinkOptions {
  readonly url: string
  readonly token: string
  readonly device: string
  readonly agents: readonly string[]
  readonly bufferLimit?: number
  readonly onFrame?: (text: string) => void
  readonly onOnline?: () => void
}

const MAX_BACKOFF_MS = 30_000

export class NodeLink {
  private socket: WebSocket | undefined
  private readonly queue: string[] = []
  private attempts = 0
  private timer: NodeJS.Timeout | undefined
  private closed = false
  private droppedCount = 0

  constructor(private readonly options: NodeLinkOptions) {}

  get buffered(): number { return this.queue.length }
  get dropped(): number { return this.droppedCount }

  start(): void { this.dial() }

  close(): void {
    this.closed = true
    if (this.timer !== undefined) clearTimeout(this.timer)
    this.socket?.close()
  }

  sendEvent(frame: EventFrame): void {
    const text = encodeFrame(frame)
    if (this.socket?.readyState === WebSocket.OPEN) { this.socket.send(text); return }
    const limit = this.options.bufferLimit ?? 1000
    this.queue.push(text)
    while (this.queue.length > limit) { this.queue.shift(); this.droppedCount += 1 }
  }

  private dial(): void {
    if (this.closed) return
    const ws = new WebSocket(this.options.url, { headers: { authorization: `Bearer ${this.options.token}` } })
    this.socket = ws

    ws.on('open', () => {
      this.attempts = 0
      ws.send(encodeFrame({
        v: 1, type: 'hello', device: this.options.device,
        token: this.options.token, agents: [...this.options.agents],
      }))
      for (const text of this.queue.splice(0)) ws.send(text)
      this.options.onOnline?.()
    })
    ws.on('message', data => this.options.onFrame?.(String(data)))
    ws.on('close', () => this.retry())
    ws.on('error', () => { /* close 事件随后触发重试 */ })
  }

  private retry(): void {
    if (this.closed) return
    const base = Math.min(MAX_BACKOFF_MS, 500 * 2 ** this.attempts)
    const delay = base * (0.5 + Math.random() / 2)
    this.attempts += 1
    this.timer = setTimeout(() => this.dial(), delay)
  }
}
```

```ts
import { randomUUID } from 'node:crypto'
import { CommandLog } from '../wire/idempotency.ts'
import { encodeFrame, type AckFrame, type CommandFrame, type EventFrame } from '../wire/frames.ts'
import type { DeviceRegistry } from './registry.ts'

export interface CommandInput {
  readonly op: CommandFrame['op']
  readonly target: CommandFrame['target']
  readonly args?: unknown
  readonly idempotencyKey: string
}

export type CommandOutcome =
  | { ok: true; result: unknown }
  | { ok: false; code: 'device-offline' | 'timeout' | string; message?: string }

export interface SessionRow {
  readonly device: string
  readonly agent: string
  readonly sessionId: string
  readonly running: boolean
  readonly updatedAt: number
  readonly cwd?: string
}

interface Pending { resolve: (outcome: CommandOutcome) => void; timer: NodeJS.Timeout }

export class HubRelay {
  private readonly pending = new Map<string, Pending>()
  private readonly log = new CommandLog()
  private readonly consumers = new Set<(event: EventFrame) => void>()
  private readonly index = new Map<string, SessionRow>()

  constructor(private readonly options: {
    registry: DeviceRegistry
    now: () => number
    timeoutMs?: number
  }) {}

  async command(input: CommandInput): Promise<CommandOutcome> {
    const cached = this.log.lookup(input.idempotencyKey)
    if (cached.hit) return { ok: true, result: cached.result }

    const slot = this.options.registry.get(input.target.device)
    if (slot === undefined) return { ok: false, code: 'device-offline' }

    const id = randomUUID()
    const frame: CommandFrame = {
      v: 1, type: 'command', id, idempotencyKey: input.idempotencyKey,
      deadline: this.options.now() + (this.options.timeoutMs ?? 30_000),
      op: input.op, target: input.target,
      ...(input.args === undefined ? {} : { args: input.args }),
    }

    const outcome = await new Promise<CommandOutcome>(resolve => {
      const timer = setTimeout(() => {
        this.pending.delete(id)
        resolve({ ok: false, code: 'timeout' })
      }, this.options.timeoutMs ?? 30_000)
      this.pending.set(id, { resolve, timer })
      slot.sender.send(encodeFrame(frame))
    })

    if (outcome.ok) this.log.remember(input.idempotencyKey, outcome.result)
    return outcome
  }

  settle(ack: AckFrame): void {
    const entry = this.pending.get(ack.id)
    if (entry === undefined) return
    clearTimeout(entry.timer)
    this.pending.delete(ack.id)
    entry.resolve(ack.ok
      ? { ok: true, result: ack.result }
      : { ok: false, code: ack.code ?? 'error', ...(ack.message === undefined ? {} : { message: ack.message }) })
  }

  /** 记录会话索引并扇出；索引只存设备/agent/sessionId/运行态，不存标题或正文。 */
  publish(event: EventFrame): void {
    const key = `${event.device}\u0000${event.agent}\u0000${event.sessionId}`
    if (event.kind === 'session.removed') {
      this.index.delete(key)
    } else if (event.kind === 'session.updated') {
      const payload = (event.payload ?? {}) as { running?: unknown; updatedAt?: unknown; cwd?: unknown }
      this.index.set(key, {
        device: event.device, agent: event.agent, sessionId: event.sessionId,
        running: payload.running === true,
        updatedAt: typeof payload.updatedAt === 'number' ? payload.updatedAt : (Date.parse(event.ts) || 0),
        ...(typeof payload.cwd === 'string' ? { cwd: payload.cwd } : {}),
      })
    }
    for (const consumer of this.consumers) consumer(event)
  }

  sessions(device?: string): SessionRow[] {
    return [...this.index.values()].filter(row => device === undefined || row.device === device)
  }

  subscribe(consumer: (event: EventFrame) => void): () => void {
    this.consumers.add(consumer)
    return () => { this.consumers.delete(consumer) }
  }
}
```

```ts
import type { EventFrame } from '../../wire/frames.ts'

interface Meta { device: string; agent: string; sessionId: string }

function asRecord(value: unknown): Record<string, unknown> | undefined {
  return typeof value === 'object' && value !== null && !Array.isArray(value)
    ? value as Record<string, unknown>
    : undefined
}

/**
 * 把 DSH 的 `SessionFollowFrame` 翻成 marshal 事件。
 * 分支以 `tests/fixtures/dsh-follow.jsonl` 为事实来源：
 * `snapshot` 不重放历史，`tool-call-delta` 不产卡片（持久 `tool/call` 才产）。
 */
export function toMarshalEvents(frame: unknown, meta: Meta, nextSeq: () => number): EventFrame[] {
  const record = asRecord(frame)
  if (record === undefined) return []

  const emit = (kind: EventFrame['kind'], payload: unknown): EventFrame[] => [{
    v: 1, type: 'event', device: meta.device, agent: meta.agent, sessionId: meta.sessionId,
    seq: nextSeq(), ts: new Date().toISOString(), kind, payload,
  }]

  if (record.type === 'assistant-stream') {
    const stream = asRecord(record.frame)
    if (stream?.type !== 'chunk') return []
    const chunk = asRecord(stream.chunk)
    if (chunk?.type === 'reasoning-delta' && typeof chunk.text === 'string') return emit('reasoning.delta', { text: chunk.text })
    if (chunk?.type === 'text-delta' && typeof chunk.text === 'string') return emit('message.delta', { text: chunk.text })
    return []
  }

  if (record.type !== 'event') return []
  const event = asRecord(record.event)
  const data = asRecord(event?.data)
  if (event === undefined || data === undefined) return []

  switch (event.type) {
    case 'turn/start':
      return emit('turn.started', { turn: data.turn })
    case 'turn/end':
      return emit('turn.completed', { turn: data.turn, reason: data.reason })
    case 'assistant/message':
      return emit('message.completed', { turn: data.turn, step: data.step })
    case 'tool/call':
      return emit('tool.started', { callId: data.callId, name: data.name, arguments: data.arguments })
    case 'tool/result': {
      const message = asRecord(data.message)
      return emit('tool.completed', {
        callId: message?.toolCallId,
        content: message?.content,
        isError: message?.isError === true || data.error !== undefined,
      })
    }
    default:
      return []
  }
}
```

```ts
    frame,

    async snapshot(signal: AbortSignal): Promise<EventFrame[]> {
      const sessions = await surface.list(signal)
      return sessions.map(session => frame(session.sessionId, 'session.updated', {
        running: session.running,
        updatedAt: session.updatedAt,
        ...(session.cwd === undefined ? {} : { cwd: session.cwd }),
      }))
    },

    async *follow(sessionId: string, signal: AbortSignal): AsyncIterable<EventFrame> {
      for await (const frame of surface.follow(sessionId, signal)) {
        yield* toMarshalEvents(frame, { device: options.device, agent: 'dsh', sessionId }, () => nextSeq(sessionId))
      }
    },

    async execute(command: { op: string; target: { sessionId: string }; args?: unknown }): Promise<unknown> {
      const known = (await surface.list(new AbortController().signal)).map(item => item.sessionId)
      if (!known.includes(command.target.sessionId)) {
        throw new Error(`session-unknown: ${command.target.sessionId}, known ${known.join(',') || '(none)'}`)
      }
      const args = (command.args ?? {}) as { text?: string; requestId?: string }
      switch (command.op) {
        case 'prompt': {
          if (typeof args.text !== 'string' || args.text.trim() === '') throw new Error('invalid-args: text is required')
          const requestId = args.requestId ?? crypto.randomUUID()
          return surface.prompt({ sessionId: command.target.sessionId, text: args.text, requestId })
        }
        case 'interrupt':
          return surface.cancel(command.target.sessionId)
        default:
          throw new Error(`unsupported: ${command.op}`)
      }
    },
  }
}
```

```ts
import type { WebServerLike } from '../dsh-types.ts'

export interface ApiOptions {
  readonly webServer: WebServerLike
  readonly registry: DeviceRegistry
  readonly relay: HubRelay
  readonly requireToken: string
}

type Handler = (req: IncomingMessage, res: ServerResponse) => void | Promise<void>

/**
 * 挂到 DSH 的 webServer 上，不自己监听端口。
 * 只登记 exact 路径：`/marshal` 与 `/marshal/api/*`，其余请求仍归 DSH。
 */
export function registerMarshalRoutes(options: ApiOptions): { dispose(): void } {
  const { webServer, registry, relay, requireToken } = options
  const disposers: (() => void)[] = []

  const json = (res: ServerResponse, status: number, body: unknown): void => {
    res.writeHead(status, { 'content-type': 'application/json', 'cache-control': 'no-store' })
    res.end(JSON.stringify(body))
  }

  const guard = (handler: Handler): Handler => (req, res) => {
    const url = new URL(req.url ?? '/', 'http://localhost')
    const header = req.headers['x-marshal-token']
    const provided = url.searchParams.get('token') ?? (Array.isArray(header) ? header[0] : header)
    if (provided !== requireToken) { res.writeHead(401).end('unauthorized'); return }
    return handler(req, res)
  }

  disposers.push(webServer.register({
    kind: 'exact', path: '/marshal',
    handler: guard((_req, res) => {
      res.writeHead(200, { 'content-type': 'text/html; charset=utf-8', 'cache-control': 'no-store' })
      res.end(PAGE_HTML)
    }),
  }))

  disposers.push(webServer.register({
    kind: 'exact', path: '/marshal/api/devices',
    handler: guard((_req, res) => { json(res, 200, { devices: registry.list(Date.now()) }) }),
  }))

  disposers.push(webServer.register({
    kind: 'exact', path: '/marshal/api/sessions',
    handler: guard((req, res) => {
      const device = new URL(req.url ?? '/', 'http://localhost').searchParams.get('device') ?? undefined
      json(res, 200, { sessions: relay.sessions(device) })
    }),
  }))

  disposers.push(webServer.register({
    kind: 'exact', path: '/marshal/api/command',
    handler: guard(async (req, res) => {
      if (req.method !== 'POST') { res.writeHead(405).end(); return }
      const chunks: Buffer[] = []
      for await (const chunk of req) chunks.push(chunk as Buffer)
      let body: { op?: string; target?: { device: string; agent: string; sessionId: string }; args?: unknown; idempotencyKey?: string }
      try { body = JSON.parse(Buffer.concat(chunks).toString('utf8')) as typeof body } catch { res.writeHead(400).end('bad json'); return }
      if (body.op === undefined || body.target === undefined || body.idempotencyKey === undefined) {
        res.writeHead(400).end('missing op/target/idempotencyKey'); return
      }
      if (!(COMMAND_OPS as readonly string[]).includes(body.op)) { res.writeHead(400).end('unknown op'); return }
      const outcome = await relay.command({
        op: body.op as CommandFrame['op'], target: body.target, args: body.args, idempotencyKey: body.idempotencyKey,
      })
      if (!outcome.ok) {
        json(res, outcome.code === 'device-offline' ? 409 : 504, outcome)
        return
      }
      json(res, 200, outcome)
    }),
  }))

  disposers.push(webServer.register({
    kind: 'exact', path: '/marshal/api/stream',
    handler: guard((req, res) => {
      res.writeHead(200, {
        'content-type': 'text/event-stream',
        'cache-control': 'no-cache',
        connection: 'keep-alive',
      })
      res.write(': connected\n\n')
      const unsubscribe = relay.subscribe(event => {
        res.write(`data: ${JSON.stringify(event)}\n\n`)
      })
      req.on('close', () => unsubscribe())
    }),
  }))

  return { dispose() { for (const dispose of disposers.reverse()) dispose() } }
}
```

```ts
import { encodeFrame, type EventFrame, type Frame } from '../wire/frames.ts'
import type { Adapter } from '../adapters/types.ts'
import type { LoggerLike } from '../dsh-types.ts'
import type { NodeLink } from './link.ts'

/** 每会话一条跟随循环；`resume` 指令只启动一次。 */
export function createFollower(options: {
  adapter: Adapter
  send: (event: EventFrame) => void
  logger: Pick<LoggerLike, 'warn'>
}) {
  const active = new Map<string, AbortController>()
  return {
    start(sessionId: string): boolean {
      if (active.has(sessionId)) return false
      const abort = new AbortController()
      active.set(sessionId, abort)
      void (async () => {
        try {
          for await (const event of options.adapter.follow(sessionId, abort.signal)) options.send(event)
        } catch (error) {
          if (!abort.signal.aborted) options.logger.warn('marshal: follow ' + sessionId + ' ended: ' + String(error))
        } finally { active.delete(sessionId) }
      })()
      return true
    },
    stopAll(): void {
      for (const abort of active.values()) abort.abort()
      active.clear()
    },
  }
}

/** 错误前缀即 wire 错误码：`session-unknown: ...` → `session-unknown`。 */
function codeOf(error: unknown): string {
  const message = error instanceof Error ? error.message : String(error)
  return /^([a-z][a-z-]*):/.exec(message)?.[1] ?? 'adapter-crashed'
}

export function runCommand(
  link: NodeLink,
  adapter: Adapter,
  follower: ReturnType<typeof createFollower>,
  frame: Frame,
  device: string,
): void {
  if (frame.type !== 'command') return
  const reply = (body: { ok: boolean; result?: unknown; code?: string; message?: string }): void => {
    link.sendRaw(encodeFrame({ v: 1, type: 'ack', id: frame.id, ...body }))
  }
  if (frame.target.device !== device) { reply({ ok: false, code: 'device-mismatch' }); return }
  if (frame.target.agent !== adapter.agent) {
    reply({ ok: false, code: 'session-unknown', message: 'agent ' + frame.target.agent + ' unavailable' })
    return
  }
  if (frame.op === 'resume') {
    follower.start(frame.target.sessionId)
    reply({ ok: true, result: { following: true } })
    return
  }
  void adapter.execute({ op: frame.op, target: { sessionId: frame.target.sessionId }, args: frame.args })
    .then(result => reply({ ok: true, result }))
    .catch((error: unknown) => reply({
      ok: false, code: codeOf(error),
      message: error instanceof Error ? error.message : String(error),
    }))
}
```

`resume` 不调 `adapter.execute`：它没有副作用可校验，跟随循环本身就是"续跑"的前置——页面选中会话后先看，再发 `prompt`。

```ts
function applyHub(ctx: MarshalContext, config: MarshalConfig): void {
  const webServer = ctx.webServer
  if (webServer === undefined) throw new Error('marshal: hub role requires the webServer service')
  const registry = new DeviceRegistry()
  const relay = new HubRelay({ registry, now: Date.now })
  const socket = mountHubSocket({
    port: webServerPort(webServer),
    registry,
    devices: loadDevices(config.devicesFile),
    now: Date.now,
    onFrame: (_device, frame) => {
      // 事件进索引并扇出；ack 必须回填，否则 relay 的每条指令都会超时。
      if (frame.type === 'event') relay.publish(frame)
      else if (frame.type === 'ack') relay.settle(frame)
    },
  })
  ctx.effect(() => { socket.dispose(); relay.dispose() }, 'marshal: uplink socket')
  ctx.effect(registerMarshalRoutes({
    webServer, registry, relay, requireToken: config.dashboardToken!,
  }).dispose, 'marshal: dashboard routes')
  ctx.logger.info(`marshal: hub ready at ${webServer.getOrigin()}/marshal`)
}

function applyNode(ctx: MarshalContext, config: MarshalConfig): void {
  const controller = ctx.sessionController
  if (controller === undefined) throw new Error('marshal: node role requires the sessionController service')

  const patterns = config.redaction.map(source => new RegExp(source, 'gi'))
  const pipeline = (event: EventFrame): EventFrame => {
    const masked = config.privacy === 'content' ? event : stripContent(event)
    return { ...masked, payload: redact(masked.payload, patterns) }
  }

  const link = new NodeLink({
    url: config.hubUrl!, token: config.token!, device: config.deviceName,
    agents: ['dsh'],
```

```ts
import { randomUUID } from 'node:crypto'
import type { SettleResult } from '../adapters/types.ts'
import type { AskUserQuestionAnswerLike, MarshalContext, UserQuestionLike } from '../dsh-types.ts'
import type { EventFrame } from '../wire/frames.ts'

interface Pending {
  readonly sessionId: string
  readonly questionIds: readonly string[]
  /** 原问题带着 options / multiSelect：结算时按它们校验标签与数量。 */
  readonly questions: readonly UserQuestionLike[]
  /** 每个 pending 只允许结算一次；答案、超时、abort、dispose 共用它。 */
  settled: boolean
  /** outcome 为 undefined 时只结束等待，不再发 `input.resolved`（发送失败或 dispose）。 */
  finish(answer: AskUserQuestionAnswerLike | undefined, outcome?: 'remote' | 'timeout' | 'local'): void
}

export interface QuestionRelay {
  settle(sessionId: string, requestId: string, answers: unknown): SettleResult
  dispose(): void
}

export interface QuestionRelayOptions {
  readonly ctx: Pick<MarshalContext, 'on'>
  readonly timeoutMs: number
  readonly send: (event: EventFrame) => void
  readonly frame: (sessionId: string, kind: EventFrame['kind'], payload: unknown) => EventFrame
}

/** 校验远端答案：每个问题 id 恰好一次，selected 必须是字符串数组。 */
export function parseAnswers(value: unknown, questionIds: readonly string[]): AskUserQuestionAnswerLike | undefined {
  if (typeof value !== 'object' || value === null) return undefined
  const raw = (value as { answers?: unknown }).answers
  if (!Array.isArray(raw)) return undefined
  const answers: { id: string; selected: string[]; custom?: string }[] = []
  for (const item of raw) {
    if (typeof item !== 'object' || item === null) return undefined
    const { id, selected, custom } = item as { id?: unknown; selected?: unknown; custom?: unknown }
    if (typeof id !== 'string' || !Array.isArray(selected) || !selected.every(label => typeof label === 'string')) return undefined
    if (custom !== undefined && typeof custom !== 'string') return undefined
    answers.push({ id, selected: selected as string[], ...(custom === undefined ? {} : { custom }) })
  }
  const seen = new Set(answers.map(answer => answer.id))
  if (seen.size !== answers.length || answers.length !== questionIds.length) return undefined
  if (!questionIds.every(id => seen.has(id))) return undefined
  return { answers }
}

/**
 * 在形状正确之后再对齐题目：标签必须来自 options，数量必须符合单选/多选规则。
 * 自定义输入（`custom`）不受数量限制，但已选标签仍要在 options 里。
 */
function validateAnswers(
  answers: AskUserQuestionAnswerLike['answers'],
  questions: readonly UserQuestionLike[],
): boolean {
  for (const answer of answers) {
    const question = questions.find(item => item.id === answer.id)
    if (question === undefined) return false
    if (Array.isArray(question.options) && question.options.length > 0) {
      const labels = new Set(
        question.options
          .map(option => option?.label)
          .filter((label): label is string => typeof label === 'string'),
      )
      if (!answer.selected.every(label => labels.has(label))) return false
    }
    if (answer.custom !== undefined) continue
    if (question.multiSelect === true) {
      if (answer.selected.length < 1) return false
    } else if (answer.selected.length !== 1) {
      return false
    }
  }
  return true
}

/**
 * 认领 `user-questions/request`：发给远端等答案，超时或无人回答就 `next()` 交回本地 UI。
 * 与 `packages/sdk/server/src/user-questions.ts` 同一写法。
 */
export function createQuestionRelay(options: QuestionRelayOptions): QuestionRelay {
  const pending = new Map<string, Pending>()
  let disposed = false

  /** 帧超过 1 MiB 时 send 会抛错；提问链路上的发送绝不能把异常带出 waterfall。 */
  const emit = (sessionId: string, kind: EventFrame['kind'], payload: unknown): boolean => {
    try {
      options.send(options.frame(sessionId, kind, payload))
      return true
    } catch {
      return false
    }
  }

  const unsubscribe = options.ctx.on('user-questions/request', async (request, next) => {
    // 已卸载的 relay 不能再认领请求，否则会留下永远不会结算的 pending。
    if (disposed) return next()
    const sessionId = request.agent?.session.id
    if (sessionId === undefined) return next()
    if (request.signal?.aborted === true) return next()

    const questions = request.questions
    const questionIds = questions.map(question => question.id)
    // 空请求或重复 id 无法满足“每个 id 恰好一次”，直接交回本地。
    if (questionIds.length === 0 || new Set(questionIds).size !== questionIds.length) return next()
    const requestId = `q-${randomUUID()}`
    const signal = request.signal

    const answered = await new Promise<AskUserQuestionAnswerLike | undefined>(resolve => {
      let timer: NodeJS.Timeout | undefined
      let onAbort: (() => void) | undefined

      const entry: Pending = {
        sessionId,
        questionIds,
        questions,
        settled: false,
        finish(answer, outcome) {
          if (entry.settled) return
          entry.settled = true
          if (timer !== undefined) clearTimeout(timer)
          if (signal !== undefined && onAbort !== undefined) signal.removeEventListener('abort', onAbort)
          pending.delete(requestId)
          if (outcome !== undefined) emit(sessionId, 'input.resolved', { requestId, outcome })
          resolve(answer)
        },
      }

      timer = setTimeout(() => entry.finish(undefined, 'timeout'), options.timeoutMs)
      pending.set(requestId, entry)
      if (signal !== undefined) {
        onAbort = () => entry.finish(undefined, 'local')
        signal.addEventListener('abort', onAbort, { once: true })
      }

      // 发不出去就按超时收拾：清掉 pending 与监听，且不再尝试发 input.resolved。
      if (!emit(sessionId, 'input.requested', { requestId, questions })) {
        entry.finish(undefined)
      }
    })

    return answered ?? next()
  })

  return {
    settle(sessionId, requestId, answers) {
      const entry = pending.get(requestId)
      if (entry === undefined) return 'unknown'
      if (entry.sessionId !== sessionId) return 'session-mismatch'
      const parsed = parseAnswers(answers, entry.questionIds)
      if (parsed === undefined) return 'invalid'
      if (!validateAnswers(parsed.answers, entry.questions)) return 'invalid'
      // 链路正在关闭时 resolved 发不出去也无妨：本地已经拿到答案。
      entry.finish(parsed, 'remote')
      return 'ok'
    },
    dispose() {
      if (disposed) return
      disposed = true
      unsubscribe()
      // 卸载时连接即将关闭：只结束等待（交回本地），不再发任何事件。
      for (const entry of [...pending.values()]) entry.finish(undefined)
      pending.clear()
    },
  }
}
```

结算只有一条路径：`finish` 用 `settled` 保证每次提问只结束一次；超时、abort 与远端答案分别带 `timeout` / `local` / `remote` 发出 `input.resolved`，发送失败或 dispose 则只结束等待、不发事件（dispose 时链路正在关闭）。`settle` 不认识的 `requestId` 返回 `unknown`，会话不符返回 `session-mismatch`，形状不对返回 `invalid` 且都保留 pending 继续等待。

`parseAnswers` 只校验形状（每个 id 恰好一次、`selected` 是字符串数组）；`validateAnswers` 再按原始问题校验语义：`selected` 标签必须来自该题的 `options`，没有 `custom` 时单选必须恰好一个、多选至少一个，带 `custom` 时数量不限但标签仍要合法。任一失败都返回 `invalid` 并保留 pending。

`emit` 接收 `(sessionId, kind, payload)` 并在 try 内部构造帧后发送，`frame()` 抛错也不会带出 waterfall。handler 开头三处直接 `next()`：relay 已 dispose、`questionIds` 为空、id 有重复（后两者无法满足“每个 id 恰好一次”）；发 `input.requested` 失败则清掉 pending 并交回本地。

```ts
function applyNode(ctx: MarshalContext, config: MarshalConfig): void {
  const controller = ctx.sessionController
  if (controller === undefined) throw new Error('marshal: node role requires the sessionController service')

  const patterns = config.redaction.map(source => new RegExp(source, 'gi'))
  const pipeline = (event: EventFrame): EventFrame => {
    const masked = config.privacy === 'content' ? event : stripContent(event)
    return { ...masked, payload: redact(masked.payload, patterns) }
  }

  const link = new NodeLink({
    url: config.hubUrl!, token: config.token!, device: config.deviceName,
    agents: ['dsh'],
    onFrame: text => {
      let frame: Frame
      try { frame = decodeFrame(text) } catch { return }
      runCommand(link, adapter, follower, frame, config.deviceName)
    },
    onError: error => ctx.logger.warn(`marshal: link error: ${String(error)}`),
  })

  let relay: QuestionRelay | undefined
  const adapter = createDshAdapter(createDshSurface(controller), {
    device: config.deviceName,
    answers: {
      settle: (sessionId, requestId, answers) => relay?.settle(sessionId, requestId, answers) ?? 'unknown',
    },
  })
  relay = config.questionRelay === 'remote'
    ? createQuestionRelay({
        ctx, timeoutMs: config.answerTimeoutMs,
        send: event => link.sendEvent(pipeline(event)),
        frame: adapter.frame,
      })
    : undefined
  const follower = createFollower({
    adapter,
    send: event => link.sendEvent(pipeline(event)),
    logger: ctx.logger,
  })

  // 快照在 effect 之外也持有同一个 signal：卸载时必须先取消，避免它在 close 之后继续产事件。
  const snapshotAbort = new AbortController()
  ctx.effect(() => { snapshotAbort.abort(); follower.stopAll(); relay?.dispose(); link.close() }, 'marshal: node link')
  link.start()

  void (async () => {
    for (const event of await adapter.snapshot(snapshotAbort.signal)) link.sendEvent(pipeline(event))
  })().catch((error: unknown) => {
    // 主动取消导致的失败不是故障，不写日志。
    if (!snapshotAbort.signal.aborted) ctx.logger.warn('marshal: snapshot failed: ' + String(error))
  })
}
```

四个顺序要点：

1. `frame: adapter.frame` 用方法引用是安全的——`frame` 是闭包，不依赖 `this`。
2. `answers.settle` 惰性读 `relay`：`relay` 在 adapter 之后才创建，但 `settle` 只在收到远端答案时才执行。
3. `link` 最先创建、`link.start()` 最后调用：`onFrame` 里引用 `adapter`/`follower` 的闭包在拨号成功前不会执行。
4. 卸载时先 `snapshotAbort.abort()` 再 `relay.dispose()` 最后 `link.close()`：relay 的 dispose 只结束等待、不发 `input.resolved`（链路即将关闭），不会在 close 之后往连接里写帧。

1. `total === 0`（没有问题或 id 都不是字符串）时卡片保持原样：只有标题，不渲染按钮。
